# Download

Searches your trackers, picks the release that matches a title's quality and language profiles,
sends it to qBittorrent, and files the finished download into your library.

What it does, what you need configured and what it will not do are documented in the plugin's own
repository: **https://github.com/fliks-app/fk-plugin-download**

This folder holds only what the catalogue publishes — the signed archive and the entry describing
each version.
